# Grimwatch 1.0.0

First public release of Grimwatch.

## Highlights

- Manage a local Markdown movie archive from the command line.
- Add, browse, search, merge, deduplicate, and mark films watched.
- Classify import lists and receive optional AI-backed recommendations.
- Keep your list portable: it remains ordinary Markdown under your control.

## Installation

Python users can install the package with `pipx install grimwatch` or `python -m pip install grimwatch`. Windows users can download `grimwatch.exe` from the matching GitHub Release.

## Notes

- AI features are optional and require your own configured API key.
- This release is tagged `v1.0.0`.
