# Security policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue. Instead, contact [Nirmal](https://github.com/Nirmal2OO8) privately through GitHub with a concise description, reproduction steps, and the affected version.

Do not include Groq, TMDb, OMDb, or PyPI API tokens in reports, issues, logs, or screenshots.

## Supported versions

Security fixes are made against the latest released version of Grimwatch.
